## Projet principal

**[gary-bourinat/windows-servers-lab](https://github.com/gary-bourinat/windows-servers-lab)** — Lab pédagogique Windows Server 2022 consacré aux services d'infrastructure Microsoft et à leur diagnostic.

- **Services :** documentation Active Directory, DNS et DHCP.
- **Administration :** utilisateurs et groupes, jonction au domaine, stratégies GPO et déploiement WDS.
- **Diagnostic et PowerShell :** commandes de vérification et script [scripts/Test-LabConnectivity.ps1](https://github.com/gary-bourinat/windows-servers-lab/blob/main/scripts/Test-LabConnectivity.ps1).

Le script réalise des diagnostics en lecture seule : interfaces IPv4 actives, passerelle et serveurs DNS configurés, test ICMP, résolution DNS facultative et état des services Windows locaux demandés.

Deux tests locaux ont été réalisés sous PowerShell 7.6.6. La validation fonctionnelle dans le lab Windows Server reste à réaliser ; les procédures documentées ne constituent pas encore des preuves d'exécution.
